# Прогнози

Приложение за телефона, което показва прогнозата „Our tip“ и коефициента
за футболните мачове от [futbol24.com](https://www.futbol24.com/betting-tips/).
Прогнозите се обновяват автоматично на всеки 30 минути.

## Как работи

1. **GitHub Actions** (`.github/workflows/update-tips.yml`) се пуска на всеки 30 минути.
2. Пуска програмата `scraper/scrape.mjs`, която отваря страниците с мачове за днес и следващите 3 дни,
   взима прогнозата и коефициента за всеки мач и ги записва в `tips.json`.
3. Публикува папката `site` заедно с новия `tips.json` в GitHub Pages.
4. Приложението на телефона чете `tips.json`. Без интернет показва последните запазени прогнози.

## Кой файл за какво е

| Файл | Какво има в него |
|---|---|
| `.github/workflows/update-tips.yml` | Кога и как се обновяват прогнозите |
| `scraper/scrape.mjs` | Извличането от futbol24 |
| `site/index.html` | Скелетът на приложението |
| `site/css/styles.css` | Цветове и външен вид |
| `site/js/config.js` | През колко минути приложението проверява за нови прогнози |
| `site/js/tip-text.js` | Преводът на прогнозите на български |
| `site/js/data.js` | Зареждането на `tips.json` |
| `site/js/render.js` | Как изглеждат дните и мачовете |
| `site/js/app.js` | Бутони, търсене, старт |
| `site/sw.js` | Офлайн режим |

## Ако прогнозите спрат да се обновяват

Отвори раздела **Actions** в хранилището. Ако последното пускане е с червен знак, отвори го
и виж стъпката „Сваляне на прогнозите“. Най-честата причина е, че futbol24 е сменил вида на страниците си.

GitHub спира автоматичните пускания, ако в хранилището няма промени 60 дни.
Тогава в **Actions** се появява бутон **Enable workflow**. Натисни го, за да ги пуснеш отново.
